
# Maths Quiz  

A simple and interactive **Maths Quiz Application** built using Python (Tkinter).  
This project provides a GUI-based quiz game where users can practice solving mathematical problems in a fun and engaging way.  

---

## Features  

-  User-friendly Graphical Interface (Tkinter).  
-  Randomly generated maths questions (Addition, Subtraction, Multiplication, Division).  
-  Score tracking system.  
-  Restart option to play again.  
-  Beginner-friendly code, easy to modify and extend.  

---

## Tech Stack  

- Python 3.12.5 
- Tkinter (for GUI)  
- Random Module (for generating questions)  

---

##  Getting Started  

### 1. Clone the Repository  
```bash
git clone https://github.com/your-username/maths-quiz.git
cd maths-quiz
```

### 2. Run the Application  
Make sure you have **Python 3.x** installed, then run:  
```bash
python maths_quiz.py
```

---


## How to Play  

1. Launch the application.  
2. A maths question will appear (e.g., `9 + 4`).  
3. Enter your answer in the input box.  
4. Click Submit to check your answer.  
5. Continue answering until the quiz ends.  
6. Your final score will be displayed.  
7. Click Restart to play again.
